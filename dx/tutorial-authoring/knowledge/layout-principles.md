# 排版基础原则

教程排版服务于「可读」与「可复现」两个目标，底层原则：

1. 结构清晰：标题层级只表达章节从属关系，不跳级；一篇教程一个 H1。
2. 篇幅服务内容：不设字数上限，但要避免啭嘨——一个段落一个意思（3–5 行为宜），无信息量的句子不写；操作步骤用有序列表，并列要点用无序列表。
3. 强调克制：粗体用于关键结论与术语首现，避免大段加粗；警示信息用统一引用块样式。
4. 中英文混排：中文与英文/数字之间加空格；中文语境用全角标点，代码与命令内保持原样。
5. 代码优先：能放代码/命令的不用文字描述；代码块必须标注语言。
6. 图文配合：截图裁剪到关键区域并紧邻文字说明；同一教程内图表风格一致。抽象概念（关系、时序、类结构等）优先用 mermaid 绘制，具体规则见 `dx:tutorial-authoring/spec/diagrams.md`。

具体强制条目见 `dx:tutorial-authoring/spec/layout.md`；可参考的公开风格指南见 `dx:tutorial-authoring/reference/external-style-guides.md`。
