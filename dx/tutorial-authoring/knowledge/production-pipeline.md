# 教程制作流程

教程制作分为七个阶段，每阶段有明确产出，作为下一阶段的输入。可执行规则见 `dx:tutorial-authoring/spec/production-pipeline.md`。

| 阶段 | 目标 | 主要产出 |
|---|---|---|
| 1. 选题 | 确定教程要解决的问题与目标读者 | 选题卡：一句话主题 + 读者画像 + 预期收获 |
| 2. 调研 | 收集并核实外部资料 | 调研记录：带 source 的结论清单 |
| 3. 大纲 | 设计章节结构与示例主线 | 章节列表 + 每章要点 + 示例规划 |
| 4. 写作 | 按大纲成文 | 教程初稿 |
| 5. 排版 | 统一格式 | 符合排版规范的成稿 |
| 6. 校对 | 验证可复现、检查事实与文字 | 校对记录；示例代码/命令全部跑通 |
| 7. 发布与维护 | 发布并跟踪反馈 | 发布版 + 过期内容回改 |

要点：
- 流程可按教程体量裁剪（小教程可合并大纲与写作），但「调研核实」与「校对跑通示例」两个环节不可省。
- 写作顺序自顶向下：先定大纲再成文，避免边写边改结构。
- 版本敏感教程（依赖特定软件版本）在选题阶段就要锁定要覆盖的版本范围。
