# 上网查资料方法

## 检索渠道
- 官方文档 / 官方博客：第一优先，从产品官网导航进入，注意选对版本分支。
- 源码仓库（GitHub 等）：README、issues、release notes 适合回答「为什么这样设计」「是否已修复」。
- 搜索引擎与 AI 检索：用于发现线索与关键词，不用作最终事实来源。
- 技术社区（Stack Overflow、论坛、群聊）：提供经验与坑位线索，结论需回官方文档验证。

## 来源可信度分层
官方文档/源码 > 权威第三方（官方认证账号、大厂工程博客）> 技术社区讨论 > 个人博客/自媒体。
版本敏感内容一律以官方最新文档为准。

## 交叉核实
- 关键结论（影响操作结果的版本号、命令、API 行为）至少两个独立来源印证，其中至少一个一手来源。
- 记录 URL 与访问日期（对应 reference 文件 frontmatter 的 `source` / `fetched`）。
- 查不到一手来源的结论，写入教程时必须标注「未验证」或舍弃。

可执行规则见 `dx:tutorial-authoring/spec/web-research.md`。
