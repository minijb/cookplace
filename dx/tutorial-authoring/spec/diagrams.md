# 图表绘制规范

关系、时序、类结构等抽象概念，默认用 mermaid 图绘制，替代纯文字描述；偏离时须说明理由。

## 图型选择

| 概念类型 | 推荐图型 |
|---|---|
| 流程 / 步骤依赖 | `flowchart`（`TD` 纵向） |
| 模块 / 角色之间的关系 | `flowchart`（`LR` 横向） |
| 调用时序 / 消息交互 | `sequenceDiagram` |
| 类 / 数据结构 | `classDiagram` |
| 状态流转 | `stateDiagram-v2` |
| 阶段排期 | `gantt` |

## 使用规则

1. 抽象概念优先画图：正文出现「A 依赖 B」「先 X 再 Y」「三层结构」这类关系描述时，配 mermaid 图，文字只做补充说明。
2. 图前后必须有文字：图前一句引入（说明这张图讲什么），关键结论在图后用文字重申，保证图不渲染也能读懂。
3. 图内文字用简短中文短语，与正文术语保持一致（术语规范见 `dx:tutorial-authoring/spec/layout.md`）；单图节点数控制在 10 个以内，超过就拆分或简化。
4. 代码块标注 `mermaid` 语言：

```mermaid
flowchart LR
  A[客户端] --> B[网关]
  B --> C[服务]
```

5. 复杂架构先给整体图再分步讲解，避免一张图塞进全部细节。
6. 教程发布平台需支持 mermaid 渲染；不支持时先渲染为图片贴出，并在文末附录保留 mermaid 源码，方便后续修改。
