# 上网查资料规范

1. 检索顺序：先官方文档/源码，再权威第三方，最后社区讨论；AI 生成内容只当线索，不当事实来源。
2. 关键结论（影响操作结果的版本号、命令、API 行为）必须有至少两个独立来源印证，其中至少一个一手来源（官方文档或源码）。
3. 版本敏感内容记录核实时的版本号与日期；教程正文中标注适用版本。
4. 教程引用外部资料必须在正文给出出处链接；来自社区讨论的经验要注明是社区经验。
5. 无法核实的说法：要么舍弃，要么明确写「未经官方验证」，禁止写成确定性结论。
6. 引用他人教程/文章的思路时注明原文出处；引用代码遵守原仓库许可协议。

偏离本规范（如时间紧迫只引单一来源）时，须记录理由与风险。
